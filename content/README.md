# Контент-план Instagram

Рабочая папка для контент-плана на месяц.

## Как работаем

1. **Бриф** — `brief.md`: кто ты, о чём блог, для кого, какая цель. Заполняется один раз, дальше уточняем.
2. **Материалы** — `materials/`: всё, что можно использовать (фото, тексты, заметки, кейсы, отзывы, голосовые в расшифровке, ссылки). Присылай в чат — я раскладываю сюда и делаю краткую опись в `materials/INDEX.md`.
3. **План** — `plan/`: календарь на месяц + готовые тексты постов, сценарии рилс и сторис.
4. **Корректировка** — правим по твоим комментариям, пока не понравится.

## Структура

```
content/
├── brief.md          # позиционирование, аудитория, цели, тон
├── materials/        # исходники
│   └── INDEX.md      # опись материалов: что есть и где использовано
└── plan/
    ├── calendar.md   # сетка на месяц: дата, формат, рубрика, тема
    └── posts/        # полные тексты и сценарии по каждой публикации
```
