# Алина Instagram - Команды

Используй эти команды в Claude Code на телефоне:

## Публикация

```
/publish "Привет, мир!"
```

```
/publish "Новый пост" --image "https://example.com/photo.jpg"
```

```
/publish "Карусель" --images "url1,url2,url3"
```

## Расписание

```
/schedule "Пост в 10:00" --time "2025-01-15 10:00"
```

## Черновики

```
/draft "Сохранить черновик"
```

## Статистика

```
/stats today
/stats week
/stats month
```

## Управление

```
/delete-post <post_id>
/edit-post <post_id> "Новый текст"
/reply <message_id> "Ответ"
```

## История

```
/history --last 10
/history --date "2025-01-14"
```
